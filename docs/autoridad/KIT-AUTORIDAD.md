## 5. Casos de éxito con cifras reales

La estructura está lista en este documento. La página se arma cuando haya un caso autorizado; antes no, porque
una página vacía no le sirve a nadie. El primer candidato es **Panamá Worldwide Express**, el proyecto con más datos.

### Mensaje para pedir la autorización

```
Hola [Nombre], ¿nos autorizas a publicar en nuestra web un caso sobre el proyecto de [empresa]? Te mandamos el texto antes de publicarlo. Contaría qué hicimos y, si estás de acuerdo, una o dos cifras como [consultas por WhatsApp al mes / posición en Google / ventas en línea], con su fuente y su fecha. Tú decides qué cifras sí y cuáles no, y puedes pedirnos que lo retiremos cuando quieras.
```

### Lo que necesito por cada caso (llénalo y mándamelo)

| Campo | Qué poner |
|---|---|
| Cliente y rubro | [Nombre de la empresa], [rubro] |
| Problema de partida | Qué no funcionaba antes, en una frase |
| Qué hicimos | Por ejemplo: rediseño, formulario por servicio, WhatsApp conectado |
| Cifra 1 (antes → después) | [Métrica]: [valor antes] → [valor después] |
| Periodo comparado | [mes y año] contra [mes y año] |
| Fuente de la cifra | GA4, Search Console, CRM o el sistema del cliente |
| Captura de la fuente | Imagen con la fecha visible |
| Quién autorizó y cuándo | Nombre, cargo y fecha, por escrito (correo o WhatsApp) |
| Cifras que NO se publican | Lo que el cliente pidió reservar |

Con eso armo la página del caso y la fila «Prueba de proyecto» de las páginas de servicio deja de decir «sin
publicar aún».
