Requisitos del VPS para evolutionpmc.com

Documento técnico para quien prepare el servidor. Al final hay un checklist con exactamente lo que debe quedar listo para entregar el acceso a Josimar.

Dominioevolutionpmc.com
SitioAstro (estático)
Backend / DBNinguno
DespliegueDocker + Coolify
1

Qué se va a alojar

evolutionpmc.com es un sitio estático hecho en Astro: se compila a HTML/CSS/JS plano, no corre un servidor de aplicación ni usa base de datos. Se empaqueta en un contenedor Docker (Node para el build, Nginx para servirlo) y se administra con Coolify, un panel de despliegue autohospedado. Por eso el VPS solo necesita correr contenedores Docker, nada de PHP, Apache ni MySQL.

2

Especificaciones mínimas del servidor

Es un sitio de bajo tráfico sin base de datos, así que no necesita un servidor grande. Estos números ya incluyen margen para correr Coolify (su panel también usa Docker) sin quedarse corto.

RecursoMínimoRecomendado
CPU1 vCPU2 vCPU
RAM2 GB4 GB
Disco25 GB SSD40 GB SSD
Transferencia1 TB/mes2 TB/mes o ilimitada
IP públicaIPv4 fija (necesaria para el DNS y el SSL)
3

Sistema operativo

Ubuntu 22.04 LTS o 24.04 LTS, instalación limpia (sin cPanel, Plesk ni panel de hosting preinstalado: Coolify hace ese trabajo). Acceso root o un usuario con privilegios sudo completos para la instalación inicial.

4

Software a instalar

Docker Engine + el plugin de Docker Compose, y luego Coolify sobre eso. Con el VPS ya accesible por SSH, la instalación de Coolify es un solo script oficial:

# Como root, en el VPS ya provisionado curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash

Ese script instala Docker si hace falta y deja el panel de Coolify corriendo en el puerto 8000. No requiere configuración manual adicional de Nginx ni de certificados: Coolify se encarga de ambos por cada aplicación que se despliegue.

5

Red y firewall

  • 22 SSH. Idealmente cambiar al puerto por defecto una vez confirmado el acceso.
  • 80 HTTP (Coolify redirige a HTTPS automáticamente).
  • 443 HTTPS.
  • 8000 Panel de Coolify. Debe quedar cerrado a internet (bloqueado en el firewall) y accesible solo por túnel SSH, mismo criterio de seguridad del resto de nuestra infraestructura.
Importante: ningún otro puerto necesita estar abierto. Si el proveedor trae un firewall administrado (ej. Security Groups), replicar esta misma regla ahí.
6

Dominio y SSL

El dominio evolutionpmc.com debe apuntar por registro A (y www como CNAME o segundo registro A) a la IP pública del VPS. El certificado SSL se emite solo (Let's Encrypt, vía Coolify) en cuanto el DNS propague, sin necesidad de comprar ni instalar nada de SSL a mano.

7

Acceso para desplegar (llave SSH)

Para subir el sitio hace falta acceso por SSH con llave pública, sin contraseña. El flujo más simple:

  • Crear un usuario con permisos sudo (puede ser el mismo root, o uno dedicado, cualquiera funciona).
  • Agregar la llave pública al archivo ~/.ssh/authorized_keys de ese usuario. Se envía por un canal seguro aparte (no por este documento).
  • Confirmar la IP del VPS y el usuario a usar (ej. root@IP o deploy@IP).
No hace falta compartir contraseñas de root ni credenciales del proveedor del VPS: con la llave SSH agregada es suficiente para desplegar.
8

Lo que NO hace falta instalar

El sitio es 100% estático, así que sobra cualquier stack pensado para PHP/WordPress u otras apps con backend:

cPanel / PleskApachePHPMySQL / MariaDBPostgreSQLFTP

Checklist de entrega

Con estos 5 puntos listos, el sitio queda en condiciones de desplegarse.

  1. VPS con Ubuntu 22.04/24.04 LTS, 2 vCPU / 4 GB RAM / 40 GB SSD (o el mínimo de la tabla arriba).
  2. Docker + Coolify instalados y el panel accesible por SSH en el puerto 8000 (cerrado a internet).
  3. Puertos 22, 80 y 443 abiertos; 8000 bloqueado desde fuera.
  4. DNS de evolutionpmc.com apuntando a la IP del VPS (registro A, más www).
  5. Usuario con sudo, IP y nombre de usuario confirmados para agregar la llave SSH.
