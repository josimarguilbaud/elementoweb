Hallazgos

Por qué tarda tanto

El más graveLa web no guarda copias de sus páginasEl servidor arma cada página desde cero en cada visita y tarda unos 2 segundos. El hosting trae un sistema de caché (LiteSpeed) pensado justo para esto, pero está instalado y apagado.
GraveSeis paquetes de complementos haciendo lo mismoEssential Addons, Happy Addons, Ultimate Addons, Premium Addons, Qi Addons y Royal Addons cargan su código en todas las páginas, aunque cada uno aporte uno o dos elementos. Por eso la portada pide 140 archivos: 78 de estilos y 88 de código.
MedioUna base de datos infladaWordPress guarda una copia cada vez que se edita una página. Ya hay 885 copias, 323 solo de la portada, y la base pesa unos 200 MB cuando una web de este tamaño debería pesar una fracción de eso.
MedioArchivos que sobran en cada visitaLa tipografía Poppins se descarga en 14 grosores aunque se usan dos o tres. Además se carga completo el paquete de íconos Font Awesome y, para todos los visitantes, los íconos del panel de administración.
SeguridadWordPress y 23 plugins sin actualizarHay versiones nuevas pendientes, varias con arreglos de seguridad. En una web que cobra en línea y recibe datos de clientes, esto no debería esperar.
PrivacidadUn plugin de pagos que no se usaWooPayments no funciona en Panamá, pero sigue activo: carga código en el checkout y consulta un servidor externo con el correo de quien está pagando.
